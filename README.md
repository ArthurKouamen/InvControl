
invcontrol est une application de gestion de stock développée en Java permettant de suivre, organiser et gérer efficacement les produits et leurs quantités.

🔧 Fonctionnalités :
- Ajout, modification et suppression de produits
- Suivi des quantités en stock
- Gestion des entrées et sorties
- Interface claire et facile à utiliser

🎯 Objectif :
Mettre en pratique les concepts de programmation orientée objet et la gestion de données en Java.
